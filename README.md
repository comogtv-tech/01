# SiamBus Express - ระบบรอบรถบัสและรับจองคิวเดินทางออนไลน์ (Bus Schedule & Travel Queue Booking System)

ระบบเว็บแอปพลิเคชันสำหรับค้นหาเที่ยวรถโดยสาร เลือกรอบรถ เลือกผังที่นั่งแบบ Interactive จองคิวและออกตั๋วเดินทางดิจิทัล (E-Ticket / Digital Queue Pass) พร้อมแดชบอร์ดจัดการสำหรับเจ้าหน้าที่นายท่า

---

## 🌟 ฟังก์ชันหลัก (Core Features)

### 🚍 1. สำหรับผู้โดยสาร (Passenger Portal)
- **ค้นหารอบรถ**: ค้นหาตามสถานีต้นทาง-ปลายทาง, วันที่เดินทาง และจำนวนผู้โดยสาร พร้อมปุ่มลัดเส้นทางยอดนิยม
- **ผังที่นั่งแบบอินเตอร์แอคทีฟ (Interactive Seat Map)**: จำลองผังที่นั่งรถบัส 1 ชั้น และ 2 ชั้น (Double Decker) แสดงสถานะที่นั่งแบบสด และคำนวณราคาอัตโนมัติ
- **กรอกข้อมูลและเลือกบริการเสริม**: ระบุชื่อผู้โดยสาร จุดรับ-จุดส่ง และเลือกบริการเสริม (ประกันเดินทาง, เพิ่มสัมภาระ)
- **ระบบจำลองการชำระเงิน**: PromptPay QR, บัตรเครดิต/เดบิต, เคาน์เตอร์เซอร์วิส
- **ออกตั๋วและบัตรคิวดิจิทัล (E-Ticket & QR Code)**: แสดงหมายเลขคิว (Queue No.) และ QR Code 2D Matrix ความละเอียดสูง พร้อมนาฬิกานับถอยหลังก่อนรถออก

### 🛠️ 2. สำหรับเจ้าหน้าที่นายท่า (Operator / Admin Dashboard)
- **สรุปภาพรวมและสถิติ**: ยอดจองรวม, รายได้รวม, อัตราการเช็คอินขึ้นรถ
- **จัดการรอบรถ (Schedule Management)**: เพิ่มรอบรถใหม่ และปรับสถานะเที่ยวรถ (ตามกำหนดเวลา, กำลังเรียกขึ้นรถ, ออกเดินทางแล้ว)
- **บัญชีรายชื่อผู้โดยสาร (Passenger Manifest)**: ตรวจสอบรายชื่อ ค้นหา และกดตรวจตั๋ว/เช็คอิน
- **ระบบประกาศเรียกคิวขึ้นรถ (Live Boarding Call)**: แบนเนอร์แจ้งเตือนพร้อมเสียงสังเคราะห์ภาษาไทย (Web Speech API)

## 📁 โครงสร้างไฟล์ในโปรเจกต์

```text
├── index.html          # หน้าหลักสำหรับค้นหาและจองตั๋ว (Passenger Portal)
├── ticket.html         # หน้าแสดงตั๋ว E-Ticket และบัตรคิวพร้อม QR Code
├── admin.html          # แดชบอร์ดจัดการรอบรถและตรวจคิวสำหรับนายท่า
├── css/
│   ├── style.css       # สไตล์หลัก ดีไซน์โมเดิร์น Glassmorphism & Responsive
│   └── seatmap.css     # สไตล์ผังที่นั่งรถบัสและแอนิเมชัน
└── js/
    ├── data.js         # ฐานข้อมูลจำลอง (สถานี, เที่ยวรถ, การจอง) พร้อม LocalStorage Sync
    ├── seatmap.js      # ตัวควบคุมผังที่นั่งและการเลือกล็อคที่นั่ง
    ├── app.js          # ตัวควบคุมขั้นตอนการจอง 4 ขั้นตอน (Step Wizard)
    ├── ticket.js       # ตัวสร้าง QR Code บน Canvas และเวลานับถอยหลัง
    └── admin.js        # ตัวควบคุมแดชบอร์ดนายท่าและการเรียกคิว
```

## 🚀 วิธีการเปิดใช้งาน (How to Run)

สามารถเปิดใช้งานได้โดยตรงบนเว็บเบราว์เซอร์:
- เปิดไฟล์ `index.html` เพื่อเข้าสู่หน้าค้นหาและจองรอบรถ
- เปิดไฟล์ `admin.html` เพื่อเข้าสู่หน้าแดชบอร์ดผู้ดูแลระบบ
